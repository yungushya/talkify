# Talkify

A simple web chat client

## Requirements

- [Node.js (v22.17.0+)](https://nodejs.org/en)

## Getting started

- Clone repository

```bash
git clone https://github.com/yungushya/talkify.git
```

- Install dependencies

```bash
npm install
```

- Run the app

```bash
npm run dev
```

The app will be available at `http://localhost:5173`
